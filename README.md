# SCORP — The Desert Is Watching

Responsive pixel-art memecoin concept site built with React, TypeScript, Vite, and CSS. The scorpion is an original temporary CSS pixel placeholder.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository into Vercel. It is configured as a Vite project (`npm run build`, output `dist`). No environment variables are required. After connecting the remote Git repository, pushes to `main` will trigger deployments.

Social destinations are placeholders until official X and Telegram URLs are supplied. Token contract and supply intentionally remain “COMING SOON.”
